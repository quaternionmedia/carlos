{# The options drawer, its device palette, the example picker and the row controls all lived here. They are gone: menus are the radial menu, per rad's interaction contract, and a second menu system would be a second answer to a question the contract already settles. See docs/rad-integration.md. This is not that. A tool palette holds the things a ring cannot express — a patch name is a text field, a file input is a file input — and it resolves no context and emits no intent, which is what a menu is. It floats over the rack rather than pinning a strip to the bottom of the window, because a rack is the width of the window and a fixed bar takes a slice of it away from every rack whether or not anyone is naming a patch. `palette` here is rad's word for a set of colour tokens, and that is what this is built from: no colour below is a literal. #}
