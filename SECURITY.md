# Security Policy

Carlos is pre-release and not yet hardened for untrusted networks or hosted
multi-user use.

## Supported Versions

Only the current default branch is supported.

## Reporting

Do not open a public issue for a vulnerability. Contact the repository owner
privately through the Quaternion Media organization contact path, then open a
public remediation issue only after the sensitive details are no longer useful
to an attacker.

## Current Boundaries

- Run Carlos locally.
- Do not expose the development server directly to the public internet.
- Do not commit real user patch databases or secret values.
